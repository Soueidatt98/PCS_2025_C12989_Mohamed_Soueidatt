## 1. Chapitre 16 : Symbolic Computations - SymPy
- SymPy permet de manipuler des expressions symboliques plutot que seulement des nombres flottants.
- `symbols` cree les variables symboliques.
- Les expressions peuvent etre developpees, factorisees, simplifiees ou substituees.
- SymPy sait deriver, integrer, calculer des limites et resoudre certaines equations.
- Les matrices symboliques sont utiles pour l'algebre exacte.
- `lambdify` transforme une expression symbolique en fonction numerique compatible avec NumPy.

## 2. Chapitre 17 : Interacting with the Operating System
- Python peut interagir avec le systeme de fichiers et les variables d'environnement.
- Les chemins doivent etre manipules prudemment, de preference avec des outils structures.
- Les scripts peuvent automatiser des taches repetitives du systeme.
- L'interaction avec des processus externes permet d'integrer Python dans un workflow plus large.
- Les differences entre systemes d'exploitation doivent etre prises en compte.
