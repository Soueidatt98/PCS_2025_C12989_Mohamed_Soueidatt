## 1. Chapitre 12 : Error and Exception Handling
- Une exception signale une erreur pendant l'execution du programme.
- `try`, `except`, `else` et `finally` permettent de traiter les erreurs proprement.
- `raise` sert a produire explicitement une exception quand une condition invalide est detectee.
- Des exceptions personnalisees rendent les erreurs plus explicites.
- Les context managers avec `with` gerent automatiquement l'ouverture et la fermeture de ressources.
- Le debogage passe par l'analyse de la pile d'appels et des outils comme `pdb`.

## 2. Chapitre 13 : Namespaces, Scopes, and Modules
- Un namespace associe des noms a des objets.
- La portee d'une variable suit l'idee LEGB : local, enclosing, global, built-in.
- Les modules organisent le code et evitent de tout garder dans un seul fichier.
- `import module` conserve le namespace du module; `from module import name` importe un nom directement.
- La variable `__name__` permet de distinguer un fichier execute directement d'un module importe.
- IPython facilite l'execution de scripts avec `%run`.
